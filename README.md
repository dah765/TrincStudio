   Версия 3.0

📖 ЧТО ЭТО?
Trinc Studio - это простой язык программирования
на русском языке со встроенной средой разработки.

🎮 ВОЗМОЖНОСТИ
✓ Все команды на русском языке
✓ Создание переменных
✓ Условия и циклы
✓ Работа со строками и списками
✓ Математические функции
✓ Система проектов
✓ Сохранение и бэкапы
✓ Тёмная/светлая тема

🚀 КАК ЗАПУСТИТЬ?
1. Запустите TrincStudio.exe
2. Напишите код в редакторе
3. Нажмите ▶ "Запустить"
4. Результат справа в окне вывода

📝 ПРИМЕР КОДА
-впиши "Калькулятор"
-ввести a
-ввести b
-переменная sum = a + b
-впиши "Сумма: "
-впиши sum
-стоп

⌨️ ВСЕ КОМАНДЫ TRINC

ВЫВОД И ВВОД:
-впиши "текст"          вывести текст
-впиши переменная        вывести переменную
-ввести переменная       ввести значение

ПЕРЕМЕННЫЕ:
-переменная x = 5        создать переменную
-число x                 преобразовать в число
-строка x                преобразовать в строку

УСЛОВИЯ:
-если x > 5 то
    -впиши "Больше"
-иначе
    -впиши "Меньше"
-конец_если

ЦИКЛЫ:
-цикл для i от 1 до 10
    -впиши i
-конец_цикла

-цикл пока i < 5
    -впиши i
    -переменная i = i + 1
-конец_цикла

СТРОКИ И СПИСКИ:
-длина переменная        длина строки
-соединить a + b -> c    объединить строки
-список x = [1,2,3]      создать список
-добавить 4 в список x   добавить элемент

МАТЕМАТИКА:
-округлить x             округлить число
-случайное от 1 до 10 -> x    случайное число

ВРЕМЯ:
-время                   показать время
-дата                    показать дату

УПРАВЛЕНИЕ:
-метка start             создать метку
-перейти start           перейти к метке
-пауза 2                 задержка в секундах
-очистить                очистить экран
-стоп                    завершить программу

ФУНКЦИИ:
-функция имя(параметр)
    -впиши параметр
    -вернуть результат
-конец_функции

📁 ПРОЕКТЫ
- Новый проект: создаёт папку с проектом
- Открыть проект: загружает существующий
- Сохранить: сохраняет текущий код
- Автосохранение: каждую минуту
- Бэкапы: в папке projects/имя/backups/

⚙️ НАСТРОЙКИ
Тема: тёмная / светлая
Цвет: зелёный / синий / красный / фиолетовый
Размер шрифта: от 10 до 20px
Папка проектов: куда сохранять проекты

⌨️ ГОРЯЧИЕ КЛАВИШИ
F5 - Запустить программу
Ctrl+S - Сохранить проект
